Household cost tools

Browser-only prototype. Calculations use only numbers you enter in this browser. Results are estimates, not retailer quotes or guaranteed savings.

Appliance electricity cost

Formula: watts ÷ 1,000 × hours/day × entered rate. Excludes standby use, tariffs, and fixed charges.

Meal cost per serving

Enter the amount of each ingredient actually used. Pantry items, waste, energy, and optional ingredients are not included unless you add them.

Bulk vs retail unit price

Use the same unit for both quantities. Add delivery or membership fees to the price if they apply.

Printer cost per page

Uses the yield you enter. Actual yield varies by coverage, print settings, maintenance, and manufacturer test method. It does not check cartridge compatibility.
